# Resume Website (HTML)

This is a simple **Resume Website** built using **pure HTML**.  
It includes sections like About Me, Skills, Experience, Projects, Education, and Contact Information.

---

## 📌 Features

- Clean resume layout using HTML
- Includes:
  - About Me section
  - Skills list
  - Experience table
  - Projects section
  - Education table
  - Contact details
- Beginner-friendly and easy to customize

---

## 🛠️ Technologies Used

- HTML5

---





##  How to Run This Project

1. Download or clone the repository  
2. Open the project folder  
3. Double-click `index.html`  
   OR  
   Open it using **Live Server** in VS Code.

---

## Customization

You can easily edit:

- Your name
- Your skills
- Experience and projects
- Education details
- Contact information
